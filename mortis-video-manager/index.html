Mortis Video Manager

供管理者個人使用的影片管理工具。程式在管理者的 Mac 執行，透過私人 Telegram 機器人提供操作入口。

YouTube 唯讀連接器

管理者完成 Google 授權後，工具可讀取自己的頻道、影片、可取得的排程狀態與分析資料，整理成庫存查詢及頻道摘要。

僅要求 youtube.readonly 與 yt-analytics.readonly。此連接器不會上傳、刪除、排程發布影片，也不讀取收益分析。

查詢與分析是附有時間的快照，不保證即時。平台影片狀態不能取代本機品質檢查與人工批准。

使用方式

  1. 由管理者本人在 Google 授權頁確認唯讀權限。
  2. 完成本機連接設定後，在已綁定的 Telegram 私人對話查詢頻道摘要。
  3. 不再使用時，撤銷 Google 授權，並依政策移除本機資料。

這個網站不是後台或登入入口，不收取 API 金鑰。請勿在公開留言貼上憑證或私人數據。

資料保護

授權憑證保存在 Mac 鑰匙圈。必要快照留在本機；摘要只傳給已確認的管理者。Google 資料不出售、不用於廣告或模型訓練。
